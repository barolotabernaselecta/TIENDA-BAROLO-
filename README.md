# Tienda Barolo · Club Barolo Selecto

Landing del club de suscripciones, tienda, regalería y club de habanos de Barolo Taberna Selecta (Yerba Buena, Tucumán).

| Archivo | Página |
|---|---|
| `index.html` | Landing del club (inicio) |
| `tienda.html` | Tienda: vinos, bebidas y packs |
| `regaleria.html` | Regalería y suscripciones de regalo |
| `habanos.html` | Club de habanos |
| `support.js`, `logo-barolo.png` | Archivos que usan las páginas |

## Publicar en Netlify

Add new site > Import a Git repository > GitHub > elegí este repositorio > Deploy. No hace falta configurar nada más.
